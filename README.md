# The Appeal Lab

The Appeal Lab is a Twitch panel extension prototype that helps creators read the room, test appeal, and turn live audience energy into interactive moments.

## Version

0.0.1

## Extension Type

Panel Extension

## Core Features

- Audience pulse checks
- Live prompts
- Viewer reactions
- Creator challenges
- Real-time engagement signals

## Twitch Paths

- Configuration Path: `config.html`
- Panel Viewer Path: `panel.html`
- Base URI for Local Test: `https://localhost:8080/`

## Status

Local Test prototype.
